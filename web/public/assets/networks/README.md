# Network logos

Source: [Trust Wallet assets](https://github.com/trustwallet/assets/tree/b26986429ed8c16b28706f99b60a4ae41b859392/blockchains).

The PNGs are copied unchanged from `blockchains/<name>/info/logo.png` at
commit `b26986429ed8c16b28706f99b60a4ae41b859392`.
`smartchain` identifies BNB Smart Chain; `avalanchec` identifies Avalanche
C-Chain; `xdai` identifies Gnosis. See the adjacent upstream MIT `LICENSE`.
Network names and logos remain the property of their respective owners.

Logos are served locally, without runtime requests to external image services.
Chain ID mappings and the default globe live in `src/NetworkIcon.tsx`.
