# Explorer / Provenance service separation

Approved in the parent conversation on 2026-11-24. Create the independent invisi-explorer project at the requested workspace path, preserving existing frontend behavior and the three services' Go/urfave-cli and React/TypeScript/Vite conventions. Explorer owns its HTTP REST API, UI, display configuration, search, pagination and rebuildable query data. Read protocol facts through Protocol RPC, recognition/evidence through Provenance JSON-RPC and optional public capabilities through Broadcaster; never share their databases or signing keys. Provenance retains ingestion, independent chain authentication, screening, proofs, publishing and machine JSON-RPC, and loses Explorer REST/static hosting. Existing issuer databases, keys and published history must remain usable. Preserve public-data filtering, Note/Credit separation, reorg/snapshot/cursor semantics and explicit missing-dependency states. Broadcaster and Provenance outages must not block available protocol history. No private tracking, witnesses or submission jobs enter the Explorer API.
